// features

Everything you need to talk SMB from Node.

A clean, dependency-free implementation that covers dialect negotiation, authentication, signing, and the file operations you actually use.

  • Dialect negotiation

    SMB 2.1, 3.0, 3.0.2 and 3.1.1 — negotiated automatically with the server.

  • NTLMv2 + SPNEGO

    Workgroup, local, and Active Directory accounts work out of the box.

  • Message signing

    HMAC-SHA256 (SMB 2.x) and AES-128-CMAC (SMB 3.x) — verified per packet.

  • Filesystem-like API

    Promise-based readFile, readdir, stat, mkdir — same shape as node:fs.

  • Streaming I/O

    Backed by Node's Readable / Writable. Pipe large files without buffering everything in memory.

  • Change notifications

    Watch directories with an AsyncIterable. Built-in backpressure handling.

  • Share enumeration

    List exposed shares with listShares(), powered by a minimal DCE/RPC layer.

  • TypeScript-first

    Strict types, exhaustive enums for SMB flags, no any in public APIs.

  • Zero runtime deps

    Audit-friendly: just standard Node APIs and node:crypto.

// quick start

Up and running in under a minute.

Install, connect with a username and password, and start reading files. Strong types guide you the rest of the way.

01

Install

Pick your package manager. The published bundle is ESM with TypeScript declarations included.

$npm install smb3-client
$pnpm add smb3-client
$yarn add smb3-client
02

Connect & read a file

A minimal end-to-end example using NTLMv2 against a Windows file share.

read-file.ts 
import { Client } from "smb3-client";

const client = new Client({
  host:     "fileserver.lan",
  port:     445,
  share:    "public",
  username: "alice",
  password: process.env.SMB_PASSWORD,
});

await client.connect();
const data = await client.readFile("readme.txt");
console.log(data.toString("utf8"));
await client.close();
03

Stream a large file

Pipe directly into any Node writable — backpressure is handled for you.

import { createWriteStream } from "node:fs";
import { pipeline } from "node:stream/promises";

await pipeline(
  client.createReadStream("backups/db.bin"),
  createWriteStream("./db.bin"),
);
04

Watch a directory

Subscribe to filesystem changes via an AsyncIterable.

for await (const change of client.watch("inbox/")) {
  console.log(change.action, change.path);
  // "added" | "removed" | "modified" | "renamed"
}

// roadmap

Honest about what works and what doesn't.

This is an alpha. Here's exactly what ships today and what's tracked for later.

Supported today

  • Dialect negotiation (SMB 2.1 → 3.1.1)
  • NTLMv2 authentication via minimal SPNEGO
  • Workgroup, local and AD accounts
  • HMAC-SHA256 and AES-128-CMAC signing
  • read, write, create, delete, rename, mkdir, rmdir, stat, readdir
  • Streaming I/O via Readable/Writable
  • Directory change notifications (AsyncIterable)
  • Share enumeration via DCE/RPC

Tracked, not yet shipped

  • SMB 3.x encryption (AES-CCM / AES-GCM)
  • Kerberos authentication mechanisms
  • Compound (batched) requests
  • DFS referrals
  • NetBIOS over TCP/139 transport

Want one of these prioritized? Open an issue with your use case.
